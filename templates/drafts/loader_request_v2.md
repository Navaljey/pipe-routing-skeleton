## 1. 비교 방법

- 로더 초안은 **v1 형식만 읽는다.** v2 초안을 넣으면 `casing.wall` 키에서 멈춘다 (v2 = `casing.wall_thickness`).
- 그래서 로더(v1 템플릿, 시드 0, 배관 33)의 박스 목록과 expand.py(v2 초안)의 박스 목록을 종류별로 맞대어 비교했다.
  차이는 (가) **템플릿 v1 → v2 내용 변경**과 (나) **같은 내용을 다르게 해석한 것** 두 가지로 나눴다. 요청은 (나) 와 v2 새 형식이 대상이다.
- 개수: 로더 212 (구조 125 + 웹 22 + 장비별 정비 공간 14 + …) · expand 199 (장비별 정비 공간 없음, 바닥 개구부를 상자 1개로 그림).

## 3. 요청 (skeleton Code)

로더가 v2 초안을 그대로 읽어 시나리오를 펼치게 해 달라. 의미는 바꾸지 않고, v1 템플릿도 계속 읽혀야 한다 (첫 측정용 v1 결과 재현).

1. **성격 블록** — `attribute_defaults` (종류 키 → 속성) · `attribute_overrides` (장애물 id → 속성) 를 읽어 `supportable`·`penetrable`·`penetration_axis`·`access` 에 반영. 종류 키 목록 = v2 초안 `attribute_defaults` 의 13 개 (§2 13 번).
2. **이름 붙은 노즐** — 장비 `nozzles: {이름: {face, at, size}}`. `face` 6 면 (top·bottom 포함), `at` 규약은 v2 초안 머리의 `nozzle_at` 그대로 (옆면 = [면 안 수평 거리, 높이], top = [x, y]). 단자 = `장비.노즐이름`. 노즐 구경 ≠ 배관 구경이면 오류. 노즐이 없는 v1 형식 장비는 T12 그대로.
3. **계통** — `pipes[].legs: [{size, from | to}]` → `branches` (`from` 이 있으면 flow = in 합류, `to` 면 out 갈래). 중력 서비스 다리는 in 만 (D112 Q1) — 어기면 오류.
4. **v2 키 이름** — `casing.wall_thickness` (v1 `casing.wall.thickness` 도 받기), `doors`, `cable_trays[].drop_from/at/to_z`, `handrail: {height, width}`, `faces` 방위표.
5. **기준 배치 옵션** — 장비 변형·단자 흔들기 없이 템플릿 좌표 그대로 펼치기 (소유자 확인·편집기용).
6. **편집기용 출력** — 펼친 시나리오와 함께 장애물마다 템플릿 종류 키 (`attribute_defaults` 의 키) 를 meta 에 남겨 주면 편집기가 그 출력을 그대로 그린다 (expand.py 삭제 조건).

### 사양 세션이 먼저 정할 것 (형식 규칙)

- (A) 구조 부재 기준점: k·s 에서 시작 (로더) vs k·s 가 가운데 (v2 초안 주석의 뜻). 권고 = 로더 방식.
- (B) 케이싱 벽: 사각형 안쪽 vs 바깥쪽, 그리고 케이싱 안 장비 노즐 (ME_TOP 등) 을 v2 처럼 직접 적은 위치에 둘지, 로더 T6 처럼 케이싱 벽 바깥면으로 옮길지. v2 는 케이싱 벽 관통 가능이므로 **직접 적은 위치 (케이싱 안) + 벽 관통** 이 v2 의도.

## 4. 템플릿 세션이 이번에 바꾼 것 (v2 초안, 소유자 확인 2026-11-24)

- SW 펌프 흡입 데크 단자를 펌프에서 1.4 m 이상: `DECK_DN(29300, 10600 → 10000)`, `(29300, 16900 → 17500)` — 데크 관통 직관 (D96) 뒤 노즐 높이까지 꺾을 공간.

- 외판 수직 웹 = 서포트 가능 · 관통 불가 (변경 없음, 확인).
- DD 윗데크 관통 단자 2개를 종늑골 사이로: `DECK_UP(35000, 24000 → 24400)`, `(3000, 20000 → 20400)` — 종늑골 바로 아래였음. 편집기 점검이 윗데크 단자의 천장 구조를 건너뛰던 것을 없앴다 (expand.py).

## 5. 참고 — v2 초안 경로 점검 시도 (템플릿 세션 작업 공간, 2026-11-24)
