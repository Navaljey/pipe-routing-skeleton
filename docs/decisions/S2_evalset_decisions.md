## 배경 (소유자)

궁극 목표는 **숙련공을 이기는 신경망(또는 최적화)** 이다. 즉 템플릿이 아닌, **처음 보는 실제 환경**에서 최적의 다중 배관 배치를 해내는 방법을 찾는 것이다.

- 노드 수가 늘어나는 문제는 환경을 줄여서 피하지 않는다. 실제 규모 환경을 평가셋에 넣고, **노드 수에 강한 방법을 찾는 것을 선수(V3·최적화)의 과제로 둔다.**
- 무작위 박스 생성기도 "박스가 흩뿌려진 환경" 이라는 특정한 한 종류일 뿐이다. 무작위만, 또는 템플릿만으로 학습하면 둘 다 치우친다.

## D123 평가셋 구성 원칙

1. **목표 지표 = 처음 보는 실제 규모 환경에서의 성능.** 학습에 쓴 환경에서의 성능은 보조 지표다. 최종 판정은 S3 의 실제 설계(숙련공 배치) 비교로 한다.
2. **실제 규모 세트를 평가셋에 넣는다** (E2·E3, D115 에 추가).
   - 규모: 기관실(E/R) 한 데크 수준의 공간 (D124), 배관 **수백 개** (`추정:` 시작 100 → 200 → 실제 수준으로 단계적으로 늘림), 실제 같은 장애물 구성 (데크·격벽·스티프너·필라·장비·통로·정비 공간).
   - 환경을 계산이 쉽게 줄이지 않는다. S2-1 (a)안 수치(스티프너 4~8 개, 정비 공간 30 %)는 **기능 시험용 작은 세트에만** 쓴다.
3. **기준선이 못 풀어도 버리지 않는다** (D34 확장). 새 분류 **"기준선 미도달 — 자원 초과"** = 기준선이 측정 머신의 메모리·시간 한계로 끝나지 못함. 배관 단위로는 기존 분류(경로 없음·상한 소진), 시나리오 단위로는 이 분류를 함께 보고한다. 기준선이 못 푸는 환경이 선수가 이겨야 할 자리다.
   - 이 세트에서 선수의 판정은 D77 사전식 그대로다. 기준선 해가 없는 시나리오는 "선수가 Layer 0 통과 해를 냈는가" 와 그 품질을 기록한다.
4. **학습 재료 = 무작위 생성 + 템플릿 변형 혼합.** 둘 다 학습·검증 시드 범위 (D110 ⑤) 에서 생성기로 만든다. 혼합 비율은 선수가 정하고 제출 때 적는다 (`추정:` 기본 1 : 1).
   - 무작위 생성 = 어떤 모양에도 버티는 힘.
   - 템플릿 변형 = 실제 선박의 규칙성 (데크·격벽 스티프너 열·장비 열·통로).
   - (S3 이후) 실제 설계 데이터 = 숙련공의 암묵적 선호.
5. **평가는 학습에 쓰지 않은 환경으로 한다 (일반화 시험).**
   - 템플릿을 평가용과 학습용으로 나눈다. 평가용 템플릿은 학습 재료 생성에 쓰지 않는다.
   - 일반화 지표: **템플릿 하나 빼고 학습 → 뺀 템플릿에서 성능** (leave-one-template-out). 처음 보는 템플릿에서 성능이 크게 떨어지면 템플릿 종류를 늘린다.
   - 평가용 템플릿 시나리오는 Jay 가 확인한 "실제 같은" 배치로 동결한다 (템플릿당 2~3 개, `추정:`).
6. **측정 하드웨어:** 실제 규모 세트도 D122 몫 (시나리오당 CPU 2 코어) 을 따른다. 메모리 한계 (지금 머신 15 GB) 를 넘는 세트를 더 큰 머신에서 잴지는 → **M35**. 그 전까지는 지금 머신에서 재고, 넘치면 "자원 초과" 로 기록한다.

## D124 맵 단위 확장 — 설계 구역 (D4 확장)

1. **맵 단위 = 단위 블록 (D4, 40 × 40 × 10 m) 또는 설계 구역.** 설계 구역 = 설계자가 실제로 다루는 단위 (예: 기관실 한 데크, 펌프룸, 청정기실, 파이프 덕트). 크기는 입력 `block` 치수로 준다 (스키마는 이미 크기를 받는다 — S2-5 큰 맵과 같은 기능).
2. **다른 데크·구역으로 가는 배관**은 데크·격벽 관통 (D113 penetrable) 과 경계 단자로 표현한다. 곡면 외판은 범위 밖 그대로 (D11) — 박스 근사.
3. **템플릿 형식 (S2-T 단계, 신규):** 박스 목록보다 한 단계 높은 **구역 배치 설명서** (YAML 또는 표) 를 프로그램이 시나리오 JSON 으로 펼친다.
   - 항목: 구역 치수 · 데크 (높이·개구부) · 격벽 · 스티프너 **규칙** (붙는 판·간격·단면) · 필라 격자 · 통로 · 장비 목록 (이름·종류·크기·위치·노즐·변화 범위) · 배관 목록 (서비스·구경·연결 노즐) · 변화 범위 (위치·크기·배관 수 흔들기).
   - 생성기는 템플릿 + 시드로 변형을 만든다. 같은 템플릿·같은 시드 → 비트 동일.
   - 템플릿 파일과 펼친 시나리오의 sha256 을 출력에 기록한다.
   - 반복 구조 (스티프너 열 등) 는 좌표를 공유하도록 펼친다 — 같은 장애물 수에서 격자선이 적다 (S2-1 측정에서 무작위 배치가 노드 수를 키운 원인).
4. **보안:** 템플릿은 실제 도면을 옮기지 않고, 경험에 기반한 **실제와 비슷한 가상 배치** 로 만든다. 실제 선박·회사를 특정할 수 있는 이름·치수는 쓰지 않는다 (D78 원칙).
5. **첫 템플릿:** 기관실 한 데크 (예: 2nd deck), 주요 계통 배관 30~50 개로 시작 → 기준선으로 노드 수·메모리·시간을 잰 뒤 배관 수를 늘린다. 이후 데크·구역 템플릿을 추가한다 (목표 4~5 종: E/R floor · 2nd · 3rd · 상부 플랫 · 청정기실/펌프룸, `추정:`).
