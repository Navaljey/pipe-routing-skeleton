## D120 서비스별 배치 선호

### 배경 (소유자)

실제 배관 배치는 배관 이름(서비스)에 따라 우선순위와 배치 선호가 다르다. 예: FO(연료유) 배관은 다른 배관보다 낮게 설치하는 경우가 많다. V3 3단계 다중 배관 학습과 섹션 3) 최적화는 이 선호를 보면서 배치해야 한다.

학습·최적화는 점수에 있는 것만 반영할 수 있으므로 선호를 **심판 규칙으로 점수화**한다. 실제 설계 데이터로 암묵적 선호를 따라 하는 방식은 S3 이후 후보다.

### 구조 (확정)

| 층 | 의미 | 심판 처리 |
|---|---|---|
| **금지** | 어기면 설계 불가 (예: 기름 배관이 고온·전기 장비 위를 지나감) | Layer 0 — 위반 = 배관 실패 |
| **선호** | 어기면 나쁜 설계 (예: 서비스별 높이 대역, 같은 서비스 묶음, 서비스 쌍 분리 거리, 벽 쪽·통로 쪽 위치) | J 에 벌점 (kg) 을 더한다 |

- 판정 순서 (D77: 완전 성공 → 통과 수 → J) 는 바뀌지 않는다. 선호 벌점은 J 안에 들어간다.
- **기준선 A* 도 같은 벌점을 라우터 비용에 넣는다** (공정 비교). 배관 하나로 정해지는 항(높이 대역·위치)은 엣지 비용에, 배관 쌍 항(묶음·분리 거리)은 놓인 배관 기준으로 배치층 비용·마스크에 넣는다 (D90 부재 예약과 같은 방식).
- 금지 규칙에 필요한 장애물 속성(예: `hot`·`electrical`)은 D93 장애물 속성에 추가한다. 기본값 false — 기존 시나리오 불변.
- 서비스 표 (D116) 에 기준선 배치 우선순위 열이 추가될 수 있다 (규칙 표와 함께 확정).

### 선호 벌점 형식 (확정 — "가상 길이")

```
선호 벌점 (kg) = 위반 구간 길이 (m) × 계수 (무차원) × 그 배관 kg/m
```

- 뜻: "위반 1 m = 직관을 계수 m 만큼 더 돌아가는 것과 같다." 구경과 무관하게 같은 비중을 가진다.
  고정 kg 벌점은 배관 J 가 구경에 따라 100배 이상 달라서 (500A 중앙 약 7,800 kg, 15A 약 67 kg — V3 측정) 대구경에서는 무시되고 소구경에서는 지배적이 되므로 쓰지 않는다.
- 근거: J 의 꺾임 비용과 같은 논리다 (엘보 하나에 약 2R × kg/m 의 벌점이 내재, D49).
- 리듀서 배관 (D118) 은 위반 구간이 놓인 쪽 구경의 kg/m.
- **배관 쌍 항** (같은 서비스 묶음 보너스, 서비스 쌍 분리 거리 미달): 길이 = 두 배관이 조건을 만족·위반하는 겹친 구간 길이, kg/m = 두 배관 중 **작은 쪽** (`추정:`). 보너스는 음의 벌점이며, 배관 J 가 직관 + 엘보보다 작아지지 않게 한다 (`추정:`).
- 규칙 표는 규칙마다 **무차원 계수만** 적는다.

### 규칙 표 형식 (소유자 작성 중)

| 열 | 내용 |
|---|---|
| 서비스 | 서비스 코드 하나 또는 서비스 쌍 |
| 규칙 종류 | 높이 대역 · 위치 · 묶음 · 분리 거리 · 위아래 금지 · 우선순위 |
| 내용 | 예: 하부 데크 위 0~2.5 m, 분리 +200 mm |
| 층 | 금지 / 선호 |
| 계수 | 선호만 (무차원) |

### 구현 요구사항 (V3 회신 2026-11-15 반영 — 규칙 표가 오면 함께 구현)

1. 엣지 비용 항목별 조회 함수: 직관 · 엘보 · 추정 서포트 · 관통 · 선호 (`scost` 일반화). V3 탐색 하한이 같은 값을 쓴다.
2. 선호 규칙 표 sha256 을 출력 global 에 기록 (`support_standard` 형식). 표가 바뀌면 라벨 재생성 판단에 쓴다.
3. J 분해에 `preference` 항목.
4. 금지 규칙 결정적 조회 힌트 `forbidden_at(구간)` (D114 힌트 확장, 검증기와 같은 함수). V3·최적화는 금지를 마스크로 처리한다.
5. 보조 지표: 같은 통과 집합에서의 선호 벌점 합 (선호 학습 여부를 따로 보이기 위해).
6. 라우터–검증기 정합: 선호 벌점·금지 판정은 라우터·검증기가 같은 함수로 계산한다. Dijkstra 대조 시험.
7. E1 불변: 규칙 표가 없는 시나리오 (서비스 없음) 는 벌점 0·금지 없음 — E1 첫 해 41 바이트 동일.

### 평가 판

- 선호 규칙이 들어간 세트는 E3 (D115) 에 포함한다. 규칙 표 도착 시점에 따라 S2 단계 배치를 정한다 (Code 가 설계안에서 제안).
