## 배경 (V3 통보, 2026-11-17)

V3 가 1단계 측정 중 **학습 없는 admissible 하한 rg** 를 만들어 투명성을 위해 알려 왔다.

- 정의: 완화 그래프 (방향·직진·꺾임·u·구배 제약을 푼 노드 그래프) 위에서 목표까지의 최단거리. 엣지 무게 = 길이 × kg/m + 엣지 추정 서포트 (`scost`, 관통비 포함), 배치층 마스크가 전부 막힌 엣지 (`emask == 0`) 는 제외. 목표에서 역방향 Dijkstra 를 배관 라우팅마다 1회. 휴리스틱 = max(D41 h, rg).
- 실제 엣지 비용 (길이 × kg/m + 엘보 + scost) ≥ 완화 무게이므로 admissible·consistent — D40 ① 이 허용하는 최적성 보존 가속이다 (그 그래프 위 J 최적 유지).
- V3 측정 (검증 시드 40000000~09, 배관 100, 2²², 비공개 표): 컴파일 A* 대비 배관별 벽시계 중앙 1.84 배, Σ 벽시계 −46 % (사전 계산 포함), 검증기 J 81 배관 모두 동일, 쉬운 배관 16건은 사전 계산 때문에 느려짐.

**결과 불변 가속이 아니다** (D53 과 다름): 확장 순서가 바뀌므로 ① 배관당 확장 상한 (2²², D73) 안에서 성공·실패가 달라질 수 있고 ② 라우터 비용이 같은 최적 경로가 여럿이면 다른 경로를 고를 수 있다 (검증기 J 가 다를 수 있음). 그래서 기준선에 넣으면 기준선 결과가 바뀐다.

## D125 rg = 참조 속도선 (E1) · E2 부터 기준선 후보

1. **E1 기준선은 그대로 둔다.** 동결 곡선·결과·라벨 모두 유효.
2. **"A* + rg" 를 참조 속도선으로 등록한다** (참조 품질선 G2 1 m, D70·D102 와 같은 성격 — 기준선이 아니라 해석용).
   - skeleton 이 **자기 레포에 다시 구현**한다 (심판은 선수 레포 코드에 의존하지 않는다, D71). 라우터 옵션으로만 두고 기본값은 끈다.
   - 시험: 가지치기 없는 Dijkstra 와 라우터 비용 일치 (최적성), 결정성 (D72), 기존 휴리스틱만 쓸 때의 결과 불변 (옵션을 끄면 E1 첫 해 41 바이트 동일).
   - 측정: E1 첫 해를 "A* + rg" 로 한 번 돌려 참조 속도선으로 기록한다 (Layer 0 통과·완전 성공·상한 소진·J·벽시계, 기준선 대비 차이). 측정 시점은 진행 중인 메모리 측정이 끝난 뒤.
3. **선수 판정 (v3_contract 반영):**
   - 단일 배관 속도 (V3 1단계): 판정 상대는 **"A* + rg"** 다. "J·성공 조건을 만족하며 벽시계 감소" (D98) 는 A* + rg 대비로 본다. 기준선 (컴파일 A*) 대비 수치는 참고로 함께 보고한다.
   - 보고는 세 단으로 나눈다: **컴파일 A* / + rg / + rg + 학습**. **학습 이득은 rg 위에서만 인정한다** (V3 제안을 계약으로 확정). 학습 없는 선수 (D121) 가 rg 를 쓰는 것은 자유이며, 같은 세 단 보고를 한다.
   - 다중 배관 (3·4단계) 판정은 지금처럼 기준선 곡선 대비 (D77·D98). 다만 선수가 rg 를 쓰면 그 사실을 적는다.
4. **E2 부터 기준선 라우터 = A* + rg 를 기본안으로 한다** — 메모리 측정 결과 (rg 의 전체 그래프 역방향 Dijkstra 가 지연 평가 방향과 충돌하는지) 를 보고 E2 동결 전에 확정한다.
   - 채택하면 E2 의 E1 세트도 rg 기준선으로 다시 잰다 (D115 Q12 의 "첫 해 바이트 동일이면 재사용" 조건을 만족하지 못하므로 원칙대로 재측정).
   - V3 라벨: A* 최적 비용은 같으므로 빈 맵 단독 경로 라벨은 비용상 유효하다. 다만 같은 비용 다른 경로·예산 안 성공 변화가 있으므로, 채택 시 라벨 재생성 여부를 그때 V3 에 통보한다 (D86 ③).
5. **메모리 측정 보고서 (`docs/reports/memory_profile.md`) 에 rg 항목을 넣는다:** rg 사전 계산의 메모리·시간 (노드 수에 대한 증가), 지연 평가 후보 (L1~L3) 와의 호환, 호환되지 않으면 대안 (예: 지연 평가와 함께 쓸 수 있는 하한 형태).
6. 리듀서·밸브·분기 (S2-2 이후) 에서는 rg 를 확장해야 할 수 있다 (구경 2개, 밸브 비트, 티). 확장 정의는 해당 단계 설계에서 정한다.
