## D110 밸브 — 배치 대상

- 밸브 위치는 입력이 아니라 라우터가 고른다.
  - 입력 = 배관별 필요 밸브 수·종류 (S2 는 **게이트밸브 1개**).
  - `valve_positions` 는 입력에서 출력(fittings)으로 옮긴다.
- 규칙은 그대로다:
  - 직관 위 (엘보 위 불가)
  - 중심 높이 700~1,500 mm, 블록 하단 기준 (D19)
  - 전면 1 m³ 여유 (D43)
  - 무게 = §3.2 게이트밸브
- 기준선: 탐색 상태에 "밸브 놓음" 비트를 추가한다.
  - 규칙을 만족하는 직관 위에서 밸브를 놓는 전이를 둔다.
  - 목표 = 도착 ∧ 밸브 놓음.
  - 최적성 보존 (가지치기 없는 Dijkstra 대조).
- 다른 밸브 종류(체크·글로브 등)는 같은 원리이므로 이후 반영한다 → **M30**.

## D111 분기·헤더 — 배치 대상

- 티 위치는 입력이 아니라 라우터가 고른다.
  - 입력 = 주관 단자 2개 + **분기 단자 1~5개** (각 pos·kind·dir·nominal_size).
- **분기 다리 구경 ≤ 주관 구경** (소유자 결정). 로더가 확인한다 (초과면 오류).
  - 다리는 자기 구경의 유효 반경·kg/m·§3.3·서포트 간격·엘보 규칙을 쓴다.
- **티는 별도 중량이 없다** (소유자 결정).
  - 티 몸체는 주관 직관(티 중심을 지나 연속)과 분기 다리 길이(티 중심부터)로 이미 길이로 청구된다. 티 무게를 따로 더하지 않는다.
  - 축소 티 표는 없다 — 주관 이하 구경은 모두 가능하다.
  - §3.2 티 열은 쓰지 않는다고 CLAUDE.md §3.2·§5 에 표시한다.
- **티 직관** (소유자 결정): 티 중심에서 다음 관이음(엘보 접점·다른 티·밸브)까지
  - 주관 앞·뒤 ≥ 3D_주관
  - 분기 쪽 ≥ 3D_분기
  - D = 호칭경 mm (R = 1.5D 와 같은 정의). 기준점 = 티 중심은 `추정:`.
  - 티끼리 3D 구간이 겹치면 위반이다.
- **중력관(T7·T8) 흐름** (소유자 결정): 높은 곳 → 낮은 곳.
  - 분기 끝 → 티 → 주관 하류로 합류한다.
  - 다리에도 D61 계단식 하향을 적용한다 (분기 끝 높이 ≥ 티 높이).
  - 분기각은 주관 흐름 방향 기준이다.
- 검증기 branch 모듈: **"입력 branch_points 와 1 mm 일치" 조건을 삭제**하고 규칙으로만 판정한다.
  - 티는 주관 직관 위
  - 분기각 ∈ {45, 90}
  - 티 직관 3D
  - 다리 구경 ≤ 주관
  - 분기 다리에도 collision·boundary 외에 **bend·gravity_slope·support 를 모두** 적용한다 (D44 의 "주관만" 수정).
- 기준선:
  - 분기 1개 = **정확 풀이** (세 단자에서 탐색 → 티 상태에서 합 최소). 예산을 넘으면 순차 근사로 내려가고, 출력에 방법(exact / sequential)을 기록한다.
  - 분기 2~5개 = **순차 근사** (주관 먼저 → 분기를 구경 큰 순, 같으면 주관까지 거리 먼 순으로, 주관 직관 위 목표 집합 A*).
  - 예산 정의(분기·헤더 배관 1개당)는 설계안에서 제안한다.
  - 헤더(분기 2개 이상)를 순차 근사보다 잘 푸는 것이 V3 4단계 과제다 (R6).
- 출력: 배관을 트리로 기록한다 (주관 waypoints + 다리별 waypoints·구경 + 티 위치·각도). 출력 스키마를 상위 호환으로 확장한다.

## D112 장애물 3종 — M27 구현 범위

| 종류 | supportable | penetrable |
|---|---|---|
| 장비 (기존) | false | false |
| 내부 격벽·데크 | true | true (D93~D95 관통 규칙) |
| 필라·스티프너 | true | false |

- 거더·웹(정해진 구멍만 관통)은 이번 범위가 아니다. M27 에 남긴다.
- 구현:
  - supportable 장애물 면을 서포트 지지면으로 쓴다. D80 ③ 면 선택에 포함하고, 부재가 그 면 범위 안에 닿아야 하며, 표 범위는 D79 ③ 그대로다.
  - 라우터 u (D80 ⑨) 와 서포트 보조 격자선 (D87 ①) 에 반영한다.
  - penetrable 장애물 관통 = 블록 쌍 공유 격벽과 같은 함수 (D94 수직·max(3D, r) 직관·고정점, D95 관통비).
- 단일 블록 기존 세트 결과는 바뀌면 안 된다 (속성 없는 장애물은 지금과 같음) — 결과 동일 시험.

## D113 힌트 확장

support_hint (D100) 와 같은 방식 — 조회 전용, 검증기와 같은 함수:

- `tee_at(주관, 위치, 분기 방향, 분기 구경)` → 티 가능 여부와 사유 (직관 위·분기각·3D 직관·구경)
- `valve_at(배관, 위치, 축)` → 밸브 가능 여부·전면 방향·사유
- "힌트 답 = 검증기 판정" 대조 시험과 호출 비용 측정.

## D114 평가 판 — D70 수정

- **E2** = E1 + 내부 구조재 세트 (+ 큰 맵 세트, V3 2단계용)
- **E3** = E2 + 밸브·분기·헤더 세트
- 생성기: 학습용(3xxxxxxx)·검증용(4xxxxxxx) 시드에서도 같은 생성기로 만들 수 있어야 한다 (V3 학습 데이터).

  - 분기 다리 구경은 주관 이하에서 고루 나오게 한다.
