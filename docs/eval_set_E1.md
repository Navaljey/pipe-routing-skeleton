## 3. 채점 규칙 (심판 — V3 수정 불가, D71)

- **검증기 Layer 0** (CLAUDE.md §6.1): collision · boundary · bend · gravity_slope (D61 계단식) · valve · branch · support (D80 형식 모델, D89 함께 받치기, D82 묶음 + 간격 재확인) · crossing (블록 쌍, D94). 라우터·그래프와 독립, 실제 기하로 판정.
- **J** (§5): 직관 × kg/m + 엘보 (§3.4) + 티 + 밸브 + 서포트 (D80) + 관통 피스 (D95). 공유 서포트는 단위중량 비례 귀속 (D81). J_total = Layer 0 통과 배관 합 (D49).
- **다중 배관 판정 = D77 사전식**: ① 완전 성공 시나리오 수 → ② 통과 배관 수 → ③ J_total (①·② 가 같을 때만, 아니면 공통 통과 배관 J 를 보조로).
- **분모 제외** (버리지 않고 따로 보고, D34): 규칙상 불가능 — 낙차 (D64, 블록 쌍 창 포함) · 서포트 (D80 ⑩ + D106 (a)) · 단자 직관 막힘 (D106 (b)). "단독 도달 불가" 는 증명된 불가능이 아니므로 분모에 남는다.
- **결정성** (D72): 판정 결과(경로·J·실패 분류)는 병렬 수·머신 부하와 무관하게 바이트 동일 (`pipeline.deterministic_view`). 무작위 요소는 시드 고정.
- **기준선 예산** (D73 · D92 ③ · D74 · D97): 기준선 A* 의 배관당 라우팅 1회 확장 상한 2²² (블록 쌍 2²³), 실패 분류용 진단 재라우팅 × 4. **V3 에 적용되지 않는다** — V3 는 자기 결정적 예산을 정의해 제출한다.
- **판정 축** (D98): 벽시계 시간-품질 곡선. 확장 수는 보조 진단.
- **기준선 규칙**: G0 · D96 경계 단자 직관 · D105 첫 꺾임 격자선 (45·90·135°) · D59 단자 예약 · D90 부재 예약 · D89 · D82 보완. 첫 해 = anytime 첫 점 (D110 ②, 시험으로 순차 출력과 바이트 동일 확인).

## 9. V3 제출 방법 (`docs/v3_contract.md` §e 요약)

- 같은 `pipeline` · 같은 검증기 (코드 커밋 §1) 로 E1 41 시나리오를 돌린다. 라우터 = `pipeline.run(router=...)`, 다중 배관 = `pipeline.run(planner=...)`.
- 제출: 시나리오별 출력 JSON (스키마 통과) + 시간-품질 곡선 (`anytime` 과 같은 형식) + 코드 커밋 · 모델 해시 · 하드웨어 · 병렬 수 · 자기 결정적 예산 정의 (D97).
- 서포트 표: 비공개 표 (sha256 §1) 로 채점한 결과만 비교한다 — 출력 `support_standard.source = private`.
- 판정: 같은 머신 조건의 벽시계 곡선, D77 사전식 (D98). J 이득은 G0 · 참조선 둘 다 (D102), 서포트 근사 손실은 따로 (M29).
- **시드 범위 (확정, v3_contract §d):** 평가 `20260000 ~ 20269999` (E1 6 세트 전부 — 학습·튜닝·모델 선택 금지) · 학습용 `30000000 ~ 39999999` · 검증용 `40000000 ~ 49999999`.
- **라벨 (D86 · v3_contract §d2):** 학습용 시드 범위 시나리오로만, D96 + D105 이후 결과로, skeleton 커밋 · 서포트 표 해시 · 격자 변형을 함께 기록. 다중 배관 순차 배치 라벨은 D90 이후.

## 10. 판 올림 규칙 (D70 · D71)

- 심판 (검증기 · J · 평가셋 · 출력 스키마 · 시간 측정 · 실패 분류) 변경은 D 항목 → 판 올림 → 기준선 재측정으로만.
