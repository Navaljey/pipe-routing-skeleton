**최선 해 갱신은 22회 모두 "최대 J 배관 rip-up" 이었다.** 실패 배관 rip-up 과 순서 무작위 재시작은 한 번도 해를 개선하지 못했다.

**실패 배관 rip-up 이 쓸모없던 이유**
- 기본 세트 실패 배관은 전부 단독으로도 경로가 없는 중력관이다 (R5).
- 밀집 50 의 실패 배관은 아래와 같다:
  - 간섭-차단 2건
  - 단독 unreachable 다수
- 간섭-차단 2건(D74 재분류)은 rip-up 해 봐도 경로 수가 늘지 않았다.

**갱신 시점**
- 기본: 2.3~11.8분.
- 밀집: 35.8~89.8분.

**밀집 50 의 이동 수가 적은 이유**
- 120분 동안 시나리오당 이동 16~24 회뿐이다.
- 재시작 한 번이 첫 해와 비슷하게 20~40분 걸리기 때문이다.

**관찰 (`추정:` 받아들이는 기준) — 라우터 비용과 검증기 J 가 어긋나는 경우가 있다**
- anytime 은 라우터 비용(직관 + 엘보 + 추정 서포트, D57)이 줄면 해를 받아들인다.
- 그래서 검증기 J(실제 서포트)가 오히려 늘어난 "개선" 이 있다:

| 곡선 | 시나리오 | 검증기 J 변화 |
|---|---|---|
| 기본 G1 | proc_006 | +53.4 |
| 기본 G1 | proc_019 | +4.9 |
| 기본 G0 | proc_007 | +0.5 |
| 밀집 50 G0 | dense50_001 | +43.5 |
| 밀집 50 G0 | dense50_004 | +34.6 |

- 그림 밀집 J 곡선의 90분 지점 상승이 이것이다.
- 개선 판단에 검증기를 넣으면 매 이동마다 검증 비용이 든다. 그래서 라우터 비용을 유지했다. 바꾸려면 결정이 필요하다.

## 5. G1 곡선 (정보용, R5 후속)

**기본 세트, 같은 예산에서 G1 이 G0 보다 낫다.** 세트 곡선이 둘 다 있는 9.8분 이후, 모든 예산 점에서:
- Layer 0 통과 189 → **193 (+4)**. 4개 모두 G0 에서 "규칙상 가능한데 경로 없음" 이던 중력관이다:
  - proc_007 P004·P007
  - proc_009 P010
  - manual_01 P005
- 공통 189배관 J −0.29%.
- G0 만 통과한 배관은 없다.

**짧은 예산에서는 G0 가 낫다.** G1 은 첫 해가 늦다:
- t₀ 중앙 136 → 155초.
- 5분 안에 첫 해를 낸 시나리오 20/21 → 18/21.
- 5분 예산에서는 G0 쪽 시나리오가 더 많이 해를 갖는다.

**밀집 50 G1 은 이번에 재지 않았다** (D68 보완 2). S1-4 에서는 G1 이 탐색 예산 소진으로 손해였다 (M23 13 > 10, 벽시계 60초 기준).

→ D68 의 "같은 예산에서 G1 이 G0 를 지배하면 새 결정" 조건은 **기본 세트에서 약 10분 이상 예산이면 충족, 5분 이하·밀집은 미충족 또는 미측정**이다. 소유자 판단을 위해 **M25** 로 올린다.

## 6. 해석

1. **anytime 기준선의 개선 능력은 약하다** (R2). 품질은 사실상 첫 해(순차 배치)가 정한다.
   - 기본: 15분 동안 경로·통과 변화 0, J −0.05~−0.07%.
   - 밀집: 120분 동안 경로·통과 변화 0, J −0.28%.
2. **V3 가 기준선 곡선 위에 서는 길**
   - (a) 첫 해를 더 빨리 낸다 — 밀집 t₀ 28~45분.
   - (b) 같은 시간에 경로·통과 수를 늘린다 — 순차 배치가 놓친 간섭-차단·탐색 실패.
   - (c) J 를 줄인다 — 격자 기인 손실 약 5%, R4.
   - 기준선이 첫 해 이후 거의 평평하므로 (b)·(c) 의 여지가 그대로 남는다.
3. **두 축은 같은 이야기를 한다.** 확장 축의 이점은 재현성이다 (같은 시드·코드면 같은 곡선, D72).
