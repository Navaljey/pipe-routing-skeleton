# S1-3 보고 — 고정 장애물 꺾임점 정합 (D65) · 고정층 격자 보강 변형 비교 (D66)

대상: 기본 세트 (procedural 20 + 수작업 1, 205배관) · 밀집 50배관 (5 시나리오, 250배관) · 계단 확인 세트 (`scenarios/stair/`, 50배관). 30배관 세트는 생략.
라우터 = A + 추정 서포트 (D55·D57) + 예약·호 판정 (D59·D60) + 계단 규칙 (D61·D63) + **D65**, 순차 배치, 4병렬.
변형 = `pipeline --grid g0 | g1 | g2:4000 | g2:2000 | g2:1000 | g1+g2:2000`. 기본값은 G0 그대로.

## 판정

- **D65:** Dijkstra 대조 시험 통과 (`tests/test_s1_corner.py`, G1·G2 그래프 포함 `tests/test_s1_grid.py`), 라우터 규칙 불일치 **전 세트·전 변형 0** → 병합 대상.
- **G1·G2:** 옵션으로만 병합 (기본값 G0 유지). 채택은 소유자 결정 — 아래 비용 대비 효과 참고.
- **90분 초과 중단 (D66):** G2 는 세 간격 모두, G1+G2 도 **밀집 50배관에서 시나리오당 90분을 넘어** 해당 변형의 밀집 측정을 중단했다 (아래 §3). 기본·계단 세트는 모든 변형 측정 완료.

## 1. D65 효과 (S1-2 → G0)

같은 세 세트(기본·밀집 50·계단) 450 공통 경로 배관에서 **경로가 바뀐 배관 0**, 경로 찾은 배관 450 → 450, Layer 0 통과 449 → 449, J 합 856,013 → 856,013 kg (0%).
고정층 노드는 +12~21% (장애물과 r − t₁₃₅ ~ r 사이 꺾임 전용 노드), 생성 시간 약 1 → 2초/구경. 꺾임점을 장애물 쪽으로 붙여야만
더 싼 경로가 생기는 경우가 이 세트에서는 없었다 — 고정층 격자선이 팽창 면(장애물 + r)에서 생기므로 꺾임점이 r 안으로 들어갈 자리가
원래 거의 없다. 정합 원칙(라우터가 받아들이는 경로 = 검증기가 받아들이는 경로)은 시험으로 확인 (꺾임 바깥 모서리 박스 사례).

## 5. 비용 대비 효과 (G0 대비, 한 줄씩)

- **G1:** 기본 M23 5 → 1 (−4), 계단 3 → 1 (−2), 수작업 P005 해결 / 밀집 50 은 M23 12 → 16 (+4, timeout +10) — 시간 기본 +41%·밀집 +57% (최대 83분, 제한 근접), 메모리 최대 1.8 → 3.2 GB (밀집 2.5 → 4.2 GB).
- **G2 4 m:** 실패 감소 없음 (기본 T1 −1, 계단 M23 −2), J −1.3 ~ −1.7% — 시간 기본 +74%, 밀집 50 은 90분 초과로 측정 중단.
- **G2 2 m:** 실패 감소 없음 (기본 T1 −1, 계단 M23 −1), J −3.1 ~ −3.5% — 시간 기본 +150%, 밀집 50 90분 초과.
- **G2 1 m:** 실패 증가 (기본 +13, timeout 23), J −4.9 ~ −6.2% — 시간 기본 +350%, 밀집 50 0/5.
- **G1+G2 2 m:** G1 의 M23 감소가 사라짐 (기본 M23 5, 계단 3 — 커진 중력관 층에서 timeout), J −3.4% — 시간 기본 +200%, 밀집 50 90분 초과.

요약: **실패를 줄이는 것은 G1 뿐이고, 기본·계단처럼 배관이 적을 때만**이다. G2 는 J 를 1~6% 줄이지만 실패는 줄이지 못하고(오히려 timeout 증가)
시간을 1.7~4.5배 쓴다. 밀집 50 에서 "격자선 부족" 간섭-차단은 G2 4 m 로도 줄지 않았다(M19 근거). 50배관 밀집의 병목은 격자 밀도보다
탐색·배치층 표시 시간(60초 timeout)이다.
