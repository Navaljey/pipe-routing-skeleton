# S1-4b 보고 — 결정적 탐색 예산 (D72)

**날짜:** 2026-10-13
**범위:** 라우터 탐색 제한을 벽시계 60초 → 배관당 확장 상태 수 상한 (`layered.EXPAND_BUDGET` = 1,660,928) 으로 바꾸고, 기본·계단·밀집 50 G0 를 한 번 다시 돌려 S1-4 와 비교한다. 이 결과가 benchmark v1 기준선의 출발점이다.

- 전체 시험 137개 통과.

## 2. 예산값 (`추정:`)

**측정**
- dense50_002 G0, 단독 실행(병렬 1, 다른 부하 없음).

## 4. 관찰 — 예산이 "60초" 와 같은 뜻이 아니다 (M24)

**배관마다 확장 속도 차이가 크다.** S1-4 에서 탐색이 2초 넘게 걸린 배관 249개의 확장 속도:
- p10 1.96만 / 중앙 **5.51만** / p90 15.1만 확장/초 (S1-4 는 2~4개 동시 실행).
- 차이의 원인: 배치층 마스크가 많은 밀집 후반 배관, 그리고 엘보 호 정밀 판정이 많은 배관은 느리다. 단독·초반 배관은 빠르다.

**예산값이 실제로 뜻하는 것**
- 27,675 는 밀집 시나리오 전체의 시간 가중 평균이다. 느린 배관이 대부분의 시간을 차지한다.
- 그래서 1,660,928 확장은 보통 배관에게 **약 30초**에 해당하고, 느린 배관에게는 60초를 넘는다 (이번 실행 최대 211초).

**S1-4 에서 60초 안에 풀렸지만 예산을 넘는 배관: 7개**

**결과에 나타난 것**
- 기본 세트 T1 실패 2개가 이 7개 중 proc_010 P003·proc_017 P008 이다.
- 중력관 탐색 공간은 h 차원이 더해져 크다. 그래서 S1-4 에서 끝까지 탐색해 "unreachable" 로 끝나던 중력관 일부가 이제 예산 소진으로 끝난다 (기본 8 · 밀집 19).
- 밀집 간섭-차단 9 → 0 은 개선이 아니다. 단독 재라우팅(D51 분류)도 같은 예산에 걸려 "개별 경로 · 예산 소진" 으로 분류가 옮겨갔다.

**결정성은 목표대로 확보됐다.** 다만 예산의 크기를 정하는 환산 기준은 소유자 판단이 필요하다 (M24):
- (a) **그대로** 1,660,928 — 지시문의 환산을 따름. 위 손실을 기준선의 성질로 둔다.
- (b) **배관 단위 중앙 속도 기준** — 약 5.5만 × 60 ≈ 330만 (2048 배수 3,309,568). S1-4 예산 초과 7개가 모두 330만 이하라 예산 안에 든다 (배치가 바뀌는 연쇄 효과는 따로).
- (c) **2의 거듭제곱 등 단순한 값** — 예: 2²² = 4,194,304.

S1-5 측정은 (a) 로 이미 시작했다 (§5). 소유자가 (b)·(c) 를 고르면 S1-5 곡선을 다시 측정해야 한다.
