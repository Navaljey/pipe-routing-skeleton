## 6. 판단이 필요한 것

**① `추정:` 구현 근사 3건 (D80 구현 ①②⑦) — 확정 요청**

1. **서포트 보조 격자선.** 고정층에 띠 경계 좌표와 단자 첫 꺾임 좌표를 더한다. 이것이 없으면 중앙 높이 배관이 띠로 내려갈 노드가 없다. 배치와 무관한 규칙 좌표라 기준선 정의(D55)는 유지된다. 끄는 옵션은 `--no-support-lines` 이다.
2. **꺾임 구역.** 꺾을 때 u 에 2·t_θ / 수평 간격을 더한다. 검증기는 엘보 호 위를 서포트 후보로 치지 않기 때문이다. 이것을 넣기 전에는 단독 검증 실패가 5건 있었고, 넣은 뒤 0 이다.
3. **D77 ① 분모.** 규칙상 서포트 불가(⑩) 배관을 분모에서 뺀다. 이번 측정에서는 해당 배관이 0 이라 결과는 같다.

**② 통과 수가 크게 줄었다 (기본 189 → 169, 밀집 223 → 189).** 원인은 세 갈래다.
- **다른 배관이 부재를 막음 (support 위반 30건, 모두 단독으로는 통과).**
  - 라우터 근사(D80 ⑨)의 범위 밖이다.
  - 선택지:
    - (a) 라우터가 놓인 배관이 부재 자리를 막는 것도 본다. 배치층 표시에 부재 판정이 추가되므로 비용이 크다.
    - (b) 기준선의 알려진 한계로 기록한다. 다중 배관 슬롯/V3(R2) 몫으로 둔다. anytime 순서 재시작이 일부를 푼다 (proc_009).
    - (c) D 묶음처럼 서로 막는 배관을 같이 지지한다. 이것은 D80 ⑥ 확장이다.
- **예산 소진 증가 (기본 0 → 6, 밀집 6 → 22, 그중 T5 17).** 상태 u 가 탐색 공간을 넓힌다. 중력관은 h 와 u 가 함께 붙어 가장 크게 늘었다. 상한(D73)을 바꿀지는 별도 판단이다. 지금은 그대로 두고 보고만 한다.
- **표 범위 밖 = 불가 (D79 ③) 와 지지면 3종 (D22).** 블록 중앙 높이는 바닥·천장·격벽 어디에서도 표 범위(약 3 m) 밖이다. 그래서 배관이 띠로 우회한다. 실제 선박의 내부 구조재 지지가 없어 현실보다 엄격하다 (M26).
