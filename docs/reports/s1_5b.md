# S1-5b 보고 — anytime 수용 규칙 (D75) + M25 판정

**날짜:** 2026-10-15
**그림·집계:** `docs/reports/figures/s1_5b_wall.png` (벽시계 축), `s1_5b_exp.png` (누적 확장 수 축), `s1_5b_summary.json`

## 1. 조건

| 항목 | 값 |
|---|---|
| 라우터 | 변형 A, 확장 상한 2²² (D73), 진단 × 4 (D74) |
| 플래너 | anytime 기준선 + **D75 수용 규칙** — 라우터 추정 1차 → 검증기 채점, 채점 시간 포함 |
| 시드 | 0 |
| 예산 | 기본 15분 · 밀집 50 120분 |
| 곡선 | 기본 G0 · 기본 G1 · 밀집 50 G0 · **밀집 50 G1** |
| 동시 실행 | 2 고정, 이탈 없음 (아래) |
| 머신 | S1-5 와 같음 (Intel Xeon 2.80 GHz · 4 코어 · numba 0.68.0, CPU 만) |

**동시 실행 배치**
- 슬롯 A = 밀집 50 G1. 메모리 때문에 한 번에 1개만 돌렸다.
- 슬롯 B = 밀집 50 G0 → 기본 G0 → 기본 G1.
- A 가 비면 공용 줄에서 작업을 가져왔다. 마지막 작업 동안은 결과를 버리는 채움 작업 1개로 2 를 유지했다.
- 그래서 밀집 50 G1 도 "동시 실행 2" 조건으로 측정됐다. 소유자가 예상한 "동시 실행 1" 이탈은 생기지 않았다.

**S1-5 곡선과 벽시계 축으로 직접 비교하지 않는다.** 밀집 50 G0 의 t₀ 가 S1-5 33분 → 44분으로 늘었다. 원인은 두 가지다:
- 이번에는 옆 슬롯이 G1(더 무거움)이었다.
- D75 채점 시간이 플래너 시간에 들어간다.

같은 세트 안에서 G0·G1 은 같은 조건이다. 확장 축은 비교할 수 있다 — 첫 해까지 확장 수가 S1-5 와 같다.

**멈춤 초과는 라우터 호출 사이에서만 판정한 결과다:** 기본 최대 976초 / 900, 밀집 G1 7,458초 / 7,200.

## 2. D75 효과

| 곡선 | 1차 통과 후보 (검증 채점) | 검증으로 버림 | 최선 해 갱신 | 첫 해 → 최종 J_total |
|---|---|---|---|---|
| 기본 G0 | 13 | **8** | 5 | 320,599.3 → 320,367.8 (−0.07%) |
| 기본 G1 | 8 | 3 | 5 | 327,354.9 → 327,134.8 (−0.07%) |
| 밀집 50 G0 | 11 | **7** | 4 | 461,126.8 → 460,272.9 (−0.19%) |
| 밀집 50 G1 | 7 | 2 | 5 | 458,696.3 → 457,351.5 (−0.29%) |

**라우터 추정과 검증 J 가 자주 어긋난다.** 라우터 추정으로는 나아진 후보 39개 중 20개(51%)가 검증 J 로는 나빠지거나 같았다. S1-5 의 "검증 J 가 오른 개선" 5건은 이 현상의 일부였다.

**52개 곡선 모두 최선 해의 검증 점수가 사전식으로 단조다.** 통과 수가 바뀐 곡선은 없다. 검증 J 가 오른 단계는 0이다.

**품질 변화**
- 갱신은 19회 모두 최대 J 배관 rip-up 이었다.
- 경로·통과 수는 모든 곡선에서 첫 해와 같다.
- anytime 기준선이 약하다는 결론(R2)은 D75 후에도 그대로다.

## 3. M25 판정 (규칙은 측정 전에 고정)

**규칙:** 밀집 50 예산 끝(120분)에서 G1 의 Layer 0 통과 수 ≥ G0 이고, 공통 배관 J ≤ G0 +0.5% 이면 기본값 = G1.

| 밀집 50 (5, 250배관) | G0 | G1 |
|---|---|---|
| 경로 배관 | 226 | 225 |
| **Layer 0 통과** | **223** | **222** |
| 공통 221배관 J | 459,300.4 | 457,090.2 (**−0.48%**) |
| 예산 소진 (최종 해) | 6 | 15 |
| t₀ 중앙 (최소~최대) | 44분 (39~46) | 64분 (51~80) |
| 메모리 최대 | 3.4 GB | 7.2 GB |

**배관 단위 차이** — 전부 T5 중력관이다.

| 시나리오 | 배관 | G0 | G1 |
|---|---|---|---|
| dense50_000 | P007 | 통과 | 예산 소진 |
| dense50_004 | P042 | 통과 | 예산 소진 |
| dense50_004 | P031 | unreachable | 통과 |

**판정: 통과 수 222 < 223 → 조건 불충족 → 기본값 G0 유지.** 공통 J 조건(−0.48%)은 충족했지만, 통과 수 조건에서 떨어졌다.

**기본 세트는 G1 이 우위다.**
- 통과 189 → 193.
- 공통 189배관 J −0.31%.
- G0 만 통과한 배관은 0.
- 짧은 예산에서는 G0 가 빠르다: t₀ 중앙 119초 vs 159초, 5분 안 첫 해 20/21 vs 18/21.

판정 규칙은 밀집 기준이다. G1 은 옵션(`--grid g1`)으로 남는다. G1 이 밀집에서 손해 보는 이유는 S1-4 와 같다 — 중력관 층 그래프가 커져 탐색 예산을 넘긴다 (R5).
